# Sistema de Control de Stock

Sistema de gestión de stock desarrollado por **PoloDev** para comercios minoristas.

## Funcionalidades

- Gestión de productos con categorías y proveedores
- Registro de ventas con carrito y múltiples medios de pago
- Ventas en espera simultáneas
- Control de stock con alertas de stock bajo
- Ingresos de mercadería con scanner de código de barras
- Reportes exportables a PDF
- Sistema de usuarios con roles (Administrador y Vendedor)
- Actualizaciones automáticas

## Tecnologías

- C# / WPF (.NET 10)
- SQLite + Dapper
- QuestPDF
- Inno Setup

## Distribución

El sistema se distribuye mediante instalador. Las actualizaciones se entregan automáticamente a través de GitHub Releases.
